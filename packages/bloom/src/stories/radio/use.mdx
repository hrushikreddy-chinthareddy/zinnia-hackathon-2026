# Description

The radio component is meant to be used like a radio group and can take in as many options as required per use case.

This component is using the [Radix Radio Group component](https://www.radix-ui.com/primitives/docs/components/radio-group).

## Accessibility

- The component adheres to the [Radio Group WAI-ARIA design pattern](https://www.w3.org/WAI/ARIA/apg/patterns/radiobutton) and uses roving tabindex to manage focus movement among radio items.

| Key | Description |
|-----|-------------|
| Tab | Moves focus to either the checked radio item or the first radio item in the group |
| Space | When focus is on an unchecked radio item, checks it |
| ArrowDown | Moves focus and checked the next radio item in the group |
| ArrowRight | Moves the focus and checked the next radio item in the group |
| ArrowUp | Moves focus to the previous radio item in the group |
| ArrowLeft | Moves focus to the previous radio item in the group |
