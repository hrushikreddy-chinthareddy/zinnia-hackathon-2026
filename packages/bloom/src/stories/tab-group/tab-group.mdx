The Tabs component offers flexibility by allowing users to navigate sections of a single page without changing the main styles and structure of the page.

> Powered by `@radix-ui/react-tabs`, this guide dives into when and how to use it for an optimal user experience.

## Styling Tab Groups

The best way to leverage the design system is to import the css module then style whichever element you semantically need to use.
There are 3 class definition that are required to style a Tab Group component:

- **tabGroup** - this waps the entire component
- **tabList** - this wraps the group of tabItems
- **tabItem** - this should be added to each tabbable item inside tabList

```jsx
import TabGroupStyles from '@zinnia/bloom/TabGroup';
```

## When To Use

- When navigating sections within a single page without changing the route.
- However, rather that forcing users into a strict pattern for the component, we abstracted the styles for usecases outside of the intended in-page navigation. So if you need to style anchor tags as a Tab Group, you can.

## How To Use

To ensure components are accessible, always leverage a Radix-UI primitive as your base component.

**Radix-UI:** [Tabs Component](https://www.radix-ui.com/primitives/docs/components/tabs)

### Implementation with Radix-ui Tabs

{

<Tabs.Root
  activationMode="manual"
  defaultValue="tab1"
  className={tabGroupStyles.tabGroup}
>
  <Tabs.List aria-label="tabs example" className={tabGroupStyles.tabList}>
    <Tabs.Trigger value="tab1" className={tabGroupStyles.tabItem}>
      <Icon type={IconType.DOCUMENT_TEXT} /> One
    </Tabs.Trigger>
    <Tabs.Trigger value="tab2" className={tabGroupStyles.tabItem}>
      <Icon type={IconType.DOCUMENT_TEXT} /> Two
    </Tabs.Trigger>
    <Tabs.Trigger value="tab3" className={tabGroupStyles.tabItem}>
      <Icon type={IconType.DOCUMENT_TEXT} /> Three
    </Tabs.Trigger>
  </Tabs.List>
  <Tabs.Content value="tab1" className={cardStyles.card}>
    Tab one content
  </Tabs.Content>
  <Tabs.Content value="tab2" className={cardStyles.card}>
    Tab two content
  </Tabs.Content>
  <Tabs.Content value="tab3" className={cardStyles.card}>
    Tab three content
  </Tabs.Content>
</Tabs.Root>
}

```jsx
import React from 'react';
import * as Tabs from '@radix-ui/react-tabs';
import { tabGroupStyles } from '@zinnia/bloom/TabGroup';
import { cardStyles } from '@zinnia/bloom/Card';
import { Icon, IconType } from '@zinnia/bloom/components';

<Tabs.Root defaultValue="tab1" className={tabGroupStyles.tabGroup}>
  <Tabs.List aria-label="tabs example" className={tabGroupStyles.tabList}>
    <Tabs.Trigger value="tab1" className={tabGroupStyles.tabItem}>
      <Icon type={IconType.DOCUMENT_TEXT} /> One
    </Tabs.Trigger>
    <Tabs.Trigger value="tab2" className={tabGroupStyles.tabItem}>
      <Icon type={IconType.DOCUMENT_TEXT} /> Two
    </Tabs.Trigger>
    <Tabs.Trigger value="tab3" className={tabGroupStyles.tabItem}>
      <Icon type={IconType.DOCUMENT_TEXT} /> Three
    </Tabs.Trigger>
  </Tabs.List>
  <Tabs.Content value="tab1" className={cardStyles.card}>
    Tab one content
  </Tabs.Content>
  <Tabs.Content value="tab2" className={cardStyles.card}>
    Tab two content
  </Tabs.Content>
  <Tabs.Content value="tab3" className={cardStyles.card}>
    Tab three content
  </Tabs.Content>
</Tabs.Root>;
```
