## What's Available?

This component includes the checkbox along with optional label adjacent to the checkbox and label above. 
These should be used ideally as part of a form.

## Accessibility

### Screen Reader Treatment

This component is built using [RadixUI](https://www.radix-ui.com/primitives/docs/components/checkbox) and has accessibilty built out of the box. 
It also allows the input to be both labelled the the label/value adjacent to the checkbox and described by the label above it.
