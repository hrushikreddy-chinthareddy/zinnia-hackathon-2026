# Ticker Description

A component to visually describe a number value change.

More info about componenent use [here](https://zinnia-design-system.supernova-docs.io/latest/ui-base-elements/ticker-value/guidelines-hovRw5l8)

## Null handling

- If value is null or undefined, component will return as null.
- 0 is treated as 'No change'
