# Description

The button group component is meant to be used like a radio group, but with a certain button appeal.

This component wraps the [Radix toggle group](https://www.radix-ui.com/primitives/docs/components/toggle-group), which converts each item into a `<button>` with `role='radio'` so the items you pass in as props need to be either `span` or `Icon`

## Accessibility

### The Group

- Since this is a radio group under the hood, it needs a label. You can add this in one of two ways, if the design includes a label above the button group, pass in a `Label` component as a prop. If the design excludes a visual label, you will need to pass in an `aria-label` prop to describe the button group.

### The Individual

- If the buttons do not include text (e.g. they only display an icon), you will need to pass in an `aria-label` with each button item
