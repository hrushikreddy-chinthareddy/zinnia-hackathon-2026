# Getting Started

## Using Bloom

Our design system works based off design tokens defined in our [Bloom Supernova](https://zinnia-design-system.supernova-docs.io/latest/welcome-to-bloom-c04etEZt) documentation site. You will need to include our tokens in your stylesheet so components can read the values.

### Including Tokens

You can use our tokens in multiple ways! The easiest is to import our css stylesheet at the root of your application

```jsx
// App.js
import "@zdx/bloom/css";

export default function App() {
  return (
    <div>
      <h1>Welcome to my app</h1>
    </div>
  );
}
```

If you're using NextJs, then the process will vary slightly depending on which router you're using

#### Pages router

> See more in [NextJs Docs](https://nextjs.org/docs/pages/building-your-application/styling/css-modules#global-styles)

```jsx
// pages/_app.js
import "@zdx/bloom/css";

// This default export is required in a new `pages/_app.js` file.
export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />;
}
```

#### App Router

> See more in [NextJs Docs](https://nextjs.org/docs/app/building-your-application/styling/css-modules#global-styles)

```jsx
// `app/layout.tsx`
import '@zdx/bloom/css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body className="container">{children}</body>
    </html>
  )
}
```

#### CSS

> if you're importing in css and using webpack you can access node_modules with a tilde `~`

```css
/* styles/index.css */
@import "~zinnia/bloom/css";
```
