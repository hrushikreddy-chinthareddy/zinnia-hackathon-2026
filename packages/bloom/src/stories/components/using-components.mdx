# Using Components
Our components are listed in this storybook under the `COMPONENTS` section in the sidebar. To see all components (even those yet to be added) check out UI Base Elements on [Sueprnova](https://zinnia-design-system.supernova-docs.io/latest/ui-base-elements/overview-glB7Xu9Y)

## Importing Components
You can use our tokens in multiple ways! The easiest is to import our css stylesheet at the root of your application 
```jsx
// make sure tokens are imported
import '@zdx/bloom/css';
// If you want to use Bloom theme make sure to import component styles also
import '@zdx/bloom/component-styles';
// import JSX component
import { Button } '@zdx/bloom/components'

export default function App() {
  return (
    <Button>Click BUtton</Button>
  );
}
```

<Button>Click me</Button>

If you're using NextJs, then the process will vary slightly depending on which router you're using
#### Pages router
> See more in [NextJs Docs](https://nextjs.org/docs/pages/building-your-application/styling/css-modules#global-styles)
 ```jsx
 // pages/_app.js
 import '@zdx/bloom/css'

// This default export is required in a new `pages/_app.js` file.
export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

#### App Router 
> See more in [NextJs Docs](https://nextjs.org/docs/app/building-your-application/styling/css-modules#global-styles)
```jsx
// `app/layout.tsx`
import '@zdx/bloom/css'
 
export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body className="container">{children}</body>
    </html>
  )
}
```

#### CSS
> if you're importing in css and using webpack you can access node_modules with a tilde `~`
```css
/* styles/index.css */
@import '~zinnia/bloom/css'
```

### Next Steps
If the stylesheet was imported correctly you should be able to apply our styles based on our custom properties
```jsx
<div style={{
  height: 'var(--measureDimensionZSpace12)', // 48px
  width: 'var(--measureDimensionZSpace12)', // 48px
  backgroundColor: 'var(--colorPrimaryColorPrimary)' // #ff7500
}} />
```
