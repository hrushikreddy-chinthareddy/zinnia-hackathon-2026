## CSS Custom Properties
In order to keep our components consistent we do not provide access to internal classNames. This allows us to provide a convenient API leveraging CSS Custom Properties

here is a button to show you how

<Button>CSS is rad</Button>

css custom properties respect scope just like css so even if your global css looks like This
```css
:root {
  --font-family-buttons: 'Poppins';
  --font-weight-semibold: 600;
  --button-border-width: 3px;
  --button-border-radius: var(--measureDimensionRadiusMax);
}
```

you can add a selector to override any property without worrying about matching classnames and collisions with classNames

```css 
.border-lg-snowflake {
  --button-border-width: 16px;
}
```
then when you add your class to your button
```jsx
<Button className="border-lg-snowflake">CSS is rad</Button>
```` 
the final outcome should be like
<Button className='border-lg-snowflake'>CSS is rad</Button>

Custom properties will even be inherited from parent elements and you can use that to theme groups of buttons or even whole sections of your page
```jsx
<div className="border-lg-snowflake">
  <Button>CSS is rad</Button>
  <Button>CSS is rad</Button>
  <Button>CSS is rad</Button>
</div>
```
