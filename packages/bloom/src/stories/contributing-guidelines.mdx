# Code Guidelines

## HTML Principles and Conventions

## CSS

use CSS modules

- CSS module name must match component name
  - ex: BloomButton.tsx and BloomButton.module.css
- Only properties defined with css custom properties eg. `--custom-property` will be modifiable by user
- Make sure css property name matches definition in supernova!

```css
/* Button.module.css */
.button {
  --font-family-buttons: 'Poppins';
  --font-weight-semibold: 600;
  --button-border-width: 3px;
  --button-border-style: solid;
  --button-border-radius: var(--measure-dimension-radius-max);

  align-items: center;
  border-radius: var(--button-border-radius);
  color: var(--color-button-primary-button-primary-text);
  cursor: pointer;
  display: flex;
  font-family: var(--font-family-buttons);
  font-feature-settings: 'clig' off, 'liga' off;
  gap: var(--gap-none, 0px);
  justify-content: center;
  padding: var(--measure-dimension-padding-lg) var(--measure-dimension-padding-xxxxxxl);
  text-align: center;

  &:focus-visible {
    outline-style: var(--button-border-style);
    outline-width: var(--button-border-style);
    outline-offset: 6px;
    outline-color: var(--color-states-focus-focus-border);
  }

  /* Primary button */
  &.primary {
    background-color: var(--color-button-primary-button-primary-fill, #FFF);
    border: var(--button-border-width) var(--button-border-style) var(--color-button-primary-button-primary-border);
    color: var(--color-button-primary-button-primary-text);

    &:hover {
      background-color: var(--color-button-primary-button-primary-hover-fill);
      border-color: var(--primary-button-primary-hover-border);
      color: var(--color-button-secondary-button-secondary-hover-text);
    }

    &:active {
      background-color: var(--color-button-primary-button-primary-pressed-fill);
      border-color: var(--color-button-primary-button-primary-pressed-border);
      color: var(--color-button-primary-button-primary-pressed-text);
    }

    &:disabled {
      background-color: var(--color-button-primary-button-primary-inactive-fill);
      /* TODO: review border weight */
      border: var(--button-border-width) var(--button-border-style) var(--color-button-primary-button-primary-inactive-border);
      color: var(--color-button-primary-button-primary-inactive-text);
    }
  }

  /* Secondary button */
  &.secondary {
    background-color: var(--color-button-secondary-button-secondary-fill);
}
```

## Typescript

```jsx
// Button.tsx
import classes from './Button.module.css';
//
//

<button
  {...props}
  type="button"
  className={[
    classes.button,
    classes[mode],
    classes[size],
    selected && classes.selected,
    className,
  ].join(' ')}
>
  {children}
</button>;
```

### General tips

- make sure all themable elements of your styles use CSS Custom Properties with the correct alias so users can override properties at the appropriate level
  eg. changing padding only for a button instead of overriding all implementations of `padding-lg`

bad:

```css
.button {
  /*  */
  padding: var(--measure-dimension-padding-lg, 8px) var(
      --measure-dimension-padding-6xl,
      48px
    );
  /*  */
}
```

good:

```css
.button {
  /* button padding is defined in the tokens file */
  --button-padding: var(--measure-dimension-padding-lg, 8px) var(
      --measure-dimension-padding-6xl,
      48px
    );
  /*  */
  padding: var(--button-padding);
}
```

#### Client Components

- If the component includes client side interaction, add `use client` at the top of the component, so that components will compile correctly.
  More information about React Server Components vs Client Components [here](https://react.dev/reference/react/use-client)

### Conventions

- all lowercase names with hyphens
  good: bloom-button.tsx
  bad: BloomButton.tsx

- components go in `src/components` folder into their own named folder. Ex: `src/components/button/button.tsx`
- create an `index.ts` that exports components and types

```ts
export { Button } from './Button';
export type { ButtonProps } from './Button';
```

- all lowercase names with hyphens for directories
- PascalCase for component names

good: `components/bloom-button/bloom-button.tsx`

<br />
bad: `components/bloom-button/BloomButton.tsx`

- components go in `src/components` folder into their own named folder. Ex: `src/components/button/BloomButton.tsx`
- create an `index.ts` that exports components and types

```ts
// components/button/index.ts
export { Button } from './Button';
export type { ButtonProps } from './Button';
```
