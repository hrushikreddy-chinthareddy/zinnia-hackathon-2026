## Adding a new Icon

1. Import the icon as a react element in the `Icon.tsx` file
   - if icon has a filled counterpart include it with same title + Filled e.g. `CloudIcon` & `CloudIconFilled`
2. Add the icon name to the export enum object in alphabetical order!
3. Add a key/value pair to the Icons object using the IconType key and the imported element as the value
   - if there is a filled version the key should look like this "[`${IconType.CLOUD}Filled`]"
4. Update the `stroke` and/or `fill` values on the `path` in the svg file to be `currentColor`
5. remove `width` and `height` values, so they can be set dynamically from code

## Available Props

- **type:** all available icons are included in the `IconType` enum.
- **alt:** if icon is semantically meaningful to the content, include alt describe to describe the icon
- **color:** by default, the icon will match the color of the parent elements font. If the color of the icon needs to be set separately, use this attribute
- **width:** by default the width is 24px, only include this if this icon needs a custom width
- **height:** by default the width is 24px, only include this if this icon needs a custom height
- **filled:** outline version is the default displayed
- **classname:** any additional styles

### Icons - Outlined

<IconGallery>
  {Object.keys(IconType).map(key => {
    return (
      <IconItem name={key.toLowerCase()} key={key}>
        <Icon type={IconType[key]} />
      </IconItem>
    );
  })}
</IconGallery>

### Icons - Filled

<IconGallery>
  {Object.values(IconType).map((key) => {
    const filledKey = `${key}Filled`
    // Use toUpperCase for icon because looping over the values to get the right icon key
    const iconTypeKey = key.toUpperCase()

    if (!Icons.hasOwnProperty(filledKey)) {
      return
    }

    return (
      <IconItem name={key.toLowerCase()} key={`${key}Filled`}>
       <Icon type={IconType[iconTypeKey]} filled />
      </IconItem>
    );

})}

</IconGallery>
