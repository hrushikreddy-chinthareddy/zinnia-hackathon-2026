# We have a dev menu!

To turn it on, add this query param to your url:

`?..show_dev_menu..=true`

> Note that the `?` is only required if it does not currently exist in the url, otherwise use `&`

The dev menu is only available in dev and qa

Once the dev menu is on, it will appear next to the carrier logo in the nav

## Some things you can do

### Mock Farmers SSO functionality with a mock ECN

- Under `Carrier Experience` > `Farmers` > check the box to turn on Mock ECN. \
  This will set the ECN to the one associated with the SSO test account.
